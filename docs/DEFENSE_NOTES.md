# Шпаргалка на защите лабораторной №2

**Цель:** запустить собственную обученную нейронную сеть детекции YOLO26n на Android без обращения к серверу.

**Вариант:** №5. Стул, стол, кровать, диван. Базовая модель YOLO26n предварительно знает эти типы объектов из COCO, мы дообучаем четыре собственных класса.

**Этапы:** фото → координаты рамок в YOLO-текстах → деление train/val → `YOLO("yolo26n.pt").train()` → `best.pt` → `format="litert"` → `best.tflite` → запуск на Android через LiteRT `Interpreter.run` → рисование прямоугольников.

**Авторазметка:** `autolabel.py` пропускает все изображения через предобученную модель, оставляя COCO классы 56/60/59/57 и переписывая их в новые ID 0/1/2/3. Это только черновик, его нужно проверить человеком.

**Датасет:** `dataset/raw/images/...` — исходные фото по папкам, `dataset/raw/labels/...` — реальные bounding boxes. `prepare_dataset.py` делает 80/20 train/validation. Структура `prepared/images/train,val` и `prepared/labels/train,val` совместима с Ultralytics.

**Что такое mAP@0.5:** для каждого класса строится precision-recall кривая, когда прогноз считается верным при IoU прямоугольников >= 0.5, из неё считается AP, затем AP усредняются по четырём классам. Целевое `>=0.8` относится к независимым тестовым картинкам, не к тренировочным.

**Что измеряем на Android:** длительность только `interpreter.run` в миллисекундах, отдельно подготовку изображения и постобработку. В `benchmark()` 2 прогрева + 10 повторов; выводим среднее/медиану/мин/макс. `1000 / среднее_время_мс` — оценка количества вызовов модели в секунду, а НЕ измерение FPS камеры.

**Как выбирается фото:** `MainActivity.pickFolder()` вызывает стандартный файловый диалог, `collectImages()` находит все изображения рекурсивно, `bitmap()` читает файл. `FurnitureDetector.infer()` делает letterbox, RGB normalization, запускает модель и преобразует прямоугольники обратно в исходные координаты. Для raw-выхода применяется NMS в коде. `annotate()` рисует рамки поверх фото.

**Зачем Docker:** одна и та же среда Python/Ultralytics в контейнере, явный вход — подготовленный размеченный датасет, выход — веса и логи `runs/`. Исходный код `ultralytics` фиксируется коммитом submodule.

**Что нельзя говорить без подтверждения:** что тестовая точность 0.8 достигнута; что смартфон измерил конкретные миллисекунды; что приложение собиралось в Android Studio; что псевдоразметка — это ручная верифицированная разметка.
